# 竞品识别、品类基准与对比口径

对比要有参照系，孤立数字没有意义。这一步产出三样东西：竞品集合、品类基准、对比解读口径。

## 一、竞品筛选（按可行性排序）

1. **同类目头部**——用商品页的类目关键词找直接替代品：`best <category> on amazon`、`top rated <category> amazon`。
2. **类目节点浏览**——从商品页类目面包屑进入 Best Sellers 页，取排名靠前且价格区间相近的 ASIN。
3. **相似性检索**——`products similar to <ASIN>`、`alternatives to <品牌 型号>`，以及商品页的
   "Customers also bought / Frequently bought together"。
4. **价格带对齐**——优先选定价落在目标 ±40% 区间内的竞品，避免拿完全不同价格带的产品对比。

选定 **4–6 个**，并记下选取理由（同价位 / 同形态 / 同场景）写进报告，便于复核。

### 两条不可省略的约束

**1）形态必须一致。** 对比标的要和目标产品"同一类结构"：多件套（3 件套 / 4 件套 / 7 件套）只和多件套比，
单片式只和单片式比；适配类型（直排沙发 / L 形 / 躺椅 / 双人位）也要对齐。形态混比会让价格与评论资产
双双失真——实测案例：把两个评论量 9 万+ 的单片式头部拉进多件套对比组，得出"目标评论资产是竞品 5.8 倍"，
限定同形态后真实值是 1.3 倍。**头部产品的量级差距适合放在正文里当参照，不适合塞进中位数基准。**

**2）品牌必须记录。** 每个竞品都填 `brand`（页面上确实没标就留空，不要猜）。报告会在对比表列头、
柱状图横轴、散点图与 CSV 中统一用「品牌 + ASIN」标识，方便你和同事口头对齐——只报 ASIN 谁也记不住。

另外，目标与竞品必须**在同一站点、同一配送地、同一语言**下取数（见 `data_acquisition.md` 的口径硬要求），
否则价格与币种不可比。

## 二、每个竞品采集的字段

必填：**品牌、ASIN、价格、平均星级、评论总数**。尽量补齐：**BSR**。可选：月销估算、变体数、配送方式、
上架时间、卖点差异、促销标记（-10% / List 价 等）。

促销信息要如实记录：页面标了 -10% 或 List Price，就写进 `note`，避免把促销价当成常态价来对标。

## 三、品类基准计算

- **中位数优先**：价格、星级、评论数、BSR 各取中位数，抗极端值。
- 均值仅作交叉验证，不作为报告中的"品类基准"。
- 报告中统一写「基于 N 个可比竞品的中位值」，并附竞品清单。

## 四、三种对比都要做

### 横向：目标 vs 竞品 vs 品类基准

写入 `competitors` 与 `benchmark`。对比表结构：

| 指标 | 目标产品 | 竞品 A | 竞品 B | 竞品 C | 品类基准(中位) |
|------|----------|--------|--------|--------|----------------|
| 价格 | | | | | |
| 平均星级 | | | | | |
| 评论总数 | | | | | |
| BSR | | | | | |
| 月销估算 | | | | | |
| 变体数 | | | | | |

### 纵向：本期 vs 上期

写入 `trendCompare`。从价格 / BSR / 评论 / 销量的时间序列里切出两段等长区间，逐项算变化率。
BSR 的 `better` 填 `"lower"`；评论数、销量、星级填 `"higher"`。

没有时间序列时**不要假装有**：把"需要什么数据才能做纵向对比"写进 `gaps`。

### 基准达标：逐项判定

写入 `benchmark.rows`，每项给 `subject`（本 ASIN）、`benchmark`（中位数）、`unit`、`better`，
报告自动算出差距百分比与"达标 / 未达标"。

## 五、对比解读口径

| 维度 | 判定标准 | 解读要点 |
|------|----------|----------|
| 价格 vs 基准 | 偏高 >+10% / 持平 ±10% / 偏低 <-10% | 偏低要问：是价格优势，还是只能靠低价换量？ |
| 星级 vs 基准 | 领先 / 持平(±0.1) / 落后 | 必须结合评论数看样本是否充足；样本少时星级不可信 |
| 评论数 vs 基准 | 头部 / 中位 / 长尾 | 评论资产 = 曝光与转化的势能 |
| BSR vs 基准 | 数字更小 = 更靠前 | 结合类目体量解释竞争烈度 |
| 月销 vs 基准 | 按倍数描述差距 | 与价格、评分合看，判断差距来自流量还是转化 |

## 六、图表要求

横向对比至少四张柱状图（价格 / 星级 / 评论数 / BSR），**并且**必须有一张
**价格 × 评分的定位散点图**（气泡大小 = 评论数）：它能直接指出价格带空档与竞争密度，
是四张柱状图给不出的信息。

- BSR 图必须标注"数值越小排名越靠前"。
- 评论数差距大时用对数轴，并在图注说明。
- 价格图带一条品类基准参考线，一眼看出偏高还是偏低。
